# 🧮 Calculadora em Assembly (EMU8086)

Esse projeto foi desenvolvido como parte da disciplina de **Arquitetura e Organização de Computadores**. A ideia era criar uma **calculadora simples**, em linguagem Assembly, usando o EMU8086.

O foco era trabalhar com os conceitos básicos da linguagem e entender melhor como o processador lida com operações matemáticas em baixo nível.

## ✨ O que a calculadora faz

Ela realiza as 4 operações matemáticas básicas entre dois números inteiros:

- ➕ Adição  
- ➖ Subtração  
- ✖️ Multiplicação  
- ➗ Divisão  

O usuário informa os dois números, escolhe a operação e o resultado é exibido na tela.

## 🛠️ Como rodar

1. Abra o arquivo `calculadora.asm` no EMU8086.
2. Compile e execute.
3. Siga as instruções no terminal.
4. Pronto! É só testar as operações.

## 📌 O que aprendi com isso

Trabalhar com Assembly foi desafiador, mas muito interessante. Consegui:

- Entender melhor como o processador funciona por trás das linguagens de alto nível.
- Trabalhar com registradores e interrupções.
- Praticar lógica de programação num nível mais próximo do hardware.

Foi um ótimo exercício pra sair da zona de conforto e me aproximar mais do funcionamento interno dos computadores.
